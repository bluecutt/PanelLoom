# 独立文字对象

[中文](text-objects.md) | [English](text-objects.en.md)

P10 最终使用 10 个带字对象。对象的外部为透明区域，气泡内部保留白色。双联气泡可以作为一组移动；需要分别取景的两组心理气泡已拆开。

[带字气泡样式详解](lettering-styles.md)将下面每类素材与实际提示词片段对应，说明轮廓、连接关系、尾巴、字号、情绪笔势和透明区域怎样约束。

| 编号 | 形态 | 文字与用途 |
| --- | --- | --- |
| C01 | 三联对白 | 也不是.....不行吧..... / 但只准五分钟。 / 你可别想占我便宜。 |
| C02 | 独立回应 | 谢谢你，昴。 |
| C03A | 双联心理活动 | ……又来了。 / 只要这家伙露出这种表情， |
| C03B | 独立心理活动 | 我就会想起那时候。 |
| C04 | 心理活动 | 真是麻烦的家伙啊.....，末尾五点；小圈朝向上层的当前人物 |
| C05 | 无框双列文字 | 和我成为朋友吧，我会保护你的。 / 以后别再一个人躲起来了 |
| C06 | 方框旁白 | 五分钟后。 |
| C07 | 低声对白 | ……喂。 |
| C08 | 炸裂对白 | 五分钟已经到了吧？！ |
| C09 | 圆润对白 | 再多抱一会儿。 |

普通对白保持接近的字号和笔势。C08 在一致的漫画手写风格中加强笔画、字形和标点的冲击力。缩放对象会同时缩放文字，排版时结合相邻气泡检查阅读尺寸。
