# Independent Lettered Objects

[中文](text-objects.md) | [English](text-objects.en.md)

P10 uses 10 lettered objects. Exteriors are transparent; bubble interiors remain white. Connected bubbles can move as one group. The two thought groups requiring separate placement have been split.

The [style guide](lettering-styles.en.md) pairs each asset type with real prompt excerpts for contour, connections, tails, size, emotional ink gestures, and transparency. English meanings below are reading aids; the Chinese artwork and exact strings remain unchanged.

| ID | Form | Exact Chinese wording and purpose |
| --- | --- | --- |

| C02 | Single response | 谢谢你，昴。 |
| C03A | Two connected thought bubbles | ……又来了。 / 只要这家伙露出这种表情， |
| C03B | Single thought | 我就会想起那时候。 |
| C04 | Thought bubble | 真是麻烦的家伙啊.....; five final dots; beads point upward to the present-day thinker |

| C06 | Rectangular caption | 五分钟后。 |
| C07 | Quiet speech | ……喂。 |
| C08 | Explosive speech | 五分钟已经到了吧？！ |

Ordinary dialogue keeps a similar optical size and ink style. C08 intensifies strokes, shapes, and punctuation within that same lettering system. Scaling the whole object scales its letters, so check reading size against nearby bubbles.
