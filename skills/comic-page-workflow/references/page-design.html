Page design and selection

Load the current chapter beat, previous accepted page, character/visual contracts and latest page status. Resolve conflicts using the user's current decision, the latest confirmed page decision, then project contracts. Record only continuity needed by this page: wardrobe, accessories, props, relative height, handedness, room geometry and emotional state.

Dialogue

Give every text item a stable ID. Record exact wording and punctuation, speaker or narrator, reading order, container, emotional intensity and planned location. Distinguish speech balloons, thoughts, time/place narration boxes, sound effects and unboxed text. Dialogue also shapes negative space and visual rhythm.

Connected balloons can be one movable unit when the user wants them to move together. Independently placed groups need separate objects even for one speaker. Plan quiet, normal and emphatic lettering together; match accepted preceding-page typography. Update both dialogue and object mapping when the user changes text during layout exploration.

Visual design

For each panel specify shot distance and direction, picture-left/right placement, body direction, gaze, eyebrows, mouth, blush, hands/contact, clothing, background density or mood texture, and text-safe space. Distinguish picture sides from anatomical left/right. Translate personality into concrete acting; a graceful character can still have expressive anger, teasing or vulnerability.

Use flexible panel count and proportions for the story. Large panels carry important acting; insets show details or reactions. Keep the reading route explicit. Agree meaningful changes to action/story before generation; prior approval in the conversation is sufficient.

Structural-line comparison

Produce independent low-fidelity whole-page candidates unless the user names an edit base. Keep readable acting, blank balloon shapes and useful space, with no final words, pseudo-text or UI. Present promptly for user review.

Assign comparison codes per stable panel, such as A-03. Record framework selection and panel-content selection separately: the framework controls initial polygons/overlap, while content references control acting. A selected panel does not implicitly select its whole page. Save crop coordinates, raw extraction and explicitly prepared references. Include required shoulders, hair and hands even if a neighboring inset covered them; mask unrelated content in a separate preparation when needed.

Current user geometry later replaces the initialization framework. Accepted manually repaired images override generation siblings. Candidate numbers identify alternatives; the latest timestamp alone does not determine acceptance.
