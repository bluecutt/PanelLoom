# Assembly, replacement and archive

Read the native adapter and query the configured CLI capabilities. Retain complete original images under independent polygon masks. The chosen framework defines initialization; newest saved or live human geometry defines later work.

Initialize accepted art with useful crop and scale, preserving important faces, hands, mouths and props. Add accepted Complete text objects at their intended apparent font sizes. Set `clipPanelId` to a stable panel ID for cropped display, or empty for page-wide display. Set named-panel front/back relationships separately through `balloon.panelOcclusion`; use supported `autoOrder:true` when appropriate. Clipping does not define relative occlusion.

Save initialization and a separate working copy. Validate JSON, all source references, stable IDs/counts and a representative render. Use actual native init/open; a launch receipt alone does not confirm window visibility. Planning templates need conversion to the editor schema.

## Replace only requested content

For an open unsaved page, fetch the live snapshot and obtain GUI write authorization. For offline work, use the user's latest saved project. Apply only the named asset/relationship, preserving unrelated polygons, image transforms, text, clipping, layers and export scale. Choose preserve/refit explicitly when dimensions change. Verify the structural diff is limited to the requested operation. Never reset human positioning to the original line frame.

## Output

Export directly from original sources at the approved multiplier. Save the current live state separately before offline render. Check actual output dimensions and source-quality warnings; a larger output cannot create missing source detail. Final assembled output is the review candidate, with no automatic whole-page model lettering pass.

After user confirmation copy unchanged bytes to a new final version, compare SHA-256 and record format, dimensions, source, destination, matching project and manual edits absent from that project. Preserve previous finals/candidates. Chapter completion does not authorize a new chapter.

For a localized flattened-page update, retain a protected static background with only the requested opening removed, then import new art/text there. Record scale changes and avoid claiming pixel identity across changed scaling.
