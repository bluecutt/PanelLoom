Independent lettered objects

Map every approved text ID to one active object using the contract template. Record exact characters/punctuation, speaker/function, host panel, actual speaker target, container/connection, tail type/direction, reading order, emotion, intended optical font size, clipping and acceptance. Placement and speaker identity are separate: an offscreen speaker or cross-panel thought tail points toward its actual target.

Generate contour, tail and final text together per movable unit. Separate groups that need independent placement. Captions, sound effects and unboxed text use the same layer. For unboxed text, the space between glyphs is transparent, with no white slab, frame or tail.

Reference the selected balloon crop for shape and accepted lettering for type style. Request a high-resolution PNG with genuine transparent exterior, opaque white interior when boxed, clean strokes and safe margins around tips and dots. Include only contracted contour/tail/text. Match optical sizes within a balloon/group; convey emotion through weight, rhythm, controlled whole-block tilt and contour. Apply emphasis to the named emotional peaks. Preserve exact punctuation and columns, including user-specified ellipsis counts.

Example prompt

TASK: One independent lettered manga object [ID].
REFERENCES: Selected contour crop controls shape; accepted lettering crop controls typography.
TEXT: [exact approved text, punctuation, columns and order; each string once].
CONTAINER: [normal/connected/thought/caption/unboxed; movable-unit boundary].
TAIL: [type, direction and actual speaker target].
TYPE: [normal style match or specific emphasis, uniform optical size, readable margins].
OUTPUT: [aspect and resolution]; true transparent exterior; white interior when boxed.
Only contracted text/container. No characters, scenery, frame, asset ID or extra words.

Check actual alpha; a drawn checkerboard is not transparency. Preserve white interiors, antialiased contours, beads, punctuation and isolated glyph components. Local extraction, component splitting or covering a specified defect requires authorization and a separately saved lineage. Avoid global white-to-transparent conversion or deleting small components by size.

Review exact text and mapping briefly; OCR assists but cannot guarantee accuracy. Rejected objects get fresh candidates from their contracts and original selected references. Keep accepted siblings. A user-approved manual repair becomes authoritative.

Import Complete objects; scale uniformly by default. Do not mirror raster lettering to reverse its tail. Regenerate tail orientation or use the advanced separate-tail route. Check apparent font size in page coordinates, not equal bitmap widths. Keep artwork unchanged during lettering revisions.
