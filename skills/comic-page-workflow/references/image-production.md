# Image production

Use the available image-generation skill for actual generation and edits. This reference supplies creative contracts, not a separate image tool. Inspect the exact selected reference when needed and record file paths/roles rather than embedding image data in documents.

## Prompt structure

Record mode and purpose; reference authority; geometry and shot; identity and acting; text/container rules; rendering/background; protected regions; target aspect and useful margins. Identify each input's role: selected lines control composition and acting, accepted final references control identity/rendering, a hand reference controls contact, and a named edit base controls a precise repair.

For structural lines, generate an independent whole-page composition with blank balloon shapes. For finished redraw, provide only the selected panel crop plus necessary identity/style/wardrobe/contact anchors. Preserve chosen expression, gaze, head tilt, gesture, relative height and costume while adding agreed detail. Correct user-identified errors even when the source crop contains them.

Finished panel art has no words, balloons, tails, page borders, neighboring panels, IDs or UI. Retain the complete original-resolution output. Overscan useful surroundings while keeping the agreed camera distance. Long frames need wide compositions and real content; do not stretch characters or add empty bars to fit.

The project visual agreement defines color, line, values and background density. In a black-and-white project, describe conceptual hair color/blush through achromatic values or linework. An explicitly requested color illustration follows its own contract.

## Precise repair

Use the user-named clean candidate as edit base. State current defect, exact desired correction, permissible local neighbors and protected remainder. Save a separate result. Another attempt starts from that base unless the user requests a chain. A preservation prompt cannot guarantee pixel-identical generative output.

For hands identify person, anatomical side, wrist/sleeve entry, visible palm/back/edge, contact points, visible fingers and occlusions. Specify who holds fingertips, palm or wrist. Protect accepted opposing hands. If repeated failures persist, explain the remaining geometry and offer an authorized simpler gesture, clearer reference or manual repair; do not change the gesture or launch endless retries on your own.

## Records and review

Keep exact prompt, input paths/roles, raw output, dimensions, any processing lineage and acceptance state. Present requested candidates promptly; perform proportionate checks and let the user judge aesthetics. A request to reuse a saved prompt requires the actual prompt/reference list. Label a reconstruction when the original is unavailable.

Whole-page lettering and special-page generation are optional explicitly chosen branches. Each whole-page lettering retry starts from the approved clean master, protecting artwork and small insets. Ordinary assembled pages use independent lettered objects and local export.
