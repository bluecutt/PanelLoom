# Renderer compatibility

0.2 keeps the historical path when ordering/occlusion extensions are absent. Optional relationships use a stable, cycle-checked image/border/balloon sequence. Inherited single-line guards stay the pixel-identical baseline; explicit front removes only the chosen owner's visible contribution, preserving another shared contributor. Explicit-back partial-alpha artwork uses channel-linear SourceOver without painting it twice; inherited and front assets retain historical GDI gamma/AA. Old golden images are not refreshed to hide differences. Preview uses a bounded original-bitmap lease cache and smaller interactive output; settled preview restores clarity. Formal output independently re-inspects, decodes and verifies complete original sources, never reading the preview cache.

The initial zero-tolerance comparison passed P03 and P10 but found 83 P05 and 98 P09 differing edge pixels. Source paths, decoded RGBA SHA256, float destination rectangles, and the native gdiplus.dll version were identical. Isolated drawing reproduced the mismatch. Direct C# drawing inside the .NET Framework process matched the old PowerShell renderer, ruling out dynamic method binding.

Official .NET 10 source initializes GDI+ startup version 2 except on Windows 7: [GdiplusStartupInputEx](https://github.com/dotnet/winforms/blob/v10.0.0/src/System.Private.Windows.Core/src/Windows/Win32/Graphics/GdiPlus/GdiplusStartupInputEx.cs), [GdiPlusInitialization](https://github.com/dotnet/winforms/blob/v10.0.0/src/System.Private.Windows.Core/src/Windows/Win32/Graphics/GdiPlus/GdiPlusInitialization.cs).

Starting version 1 before System.Drawing initialization, retaining its token for the process lifetime, changed the native test result to exactly zero differing pixels for all four real Legacy fixtures. No comparison tolerance was relaxed. The renderer constructor calls `LegacyGdiBootstrap.Initialize`; both executable entrypoints must also call it first, before any bitmap creation. This is process-local initialization, not an OS setting or library replacement. The token is released on process exit.

Golden PNGs and private diagnostics stay under ignored `artifacts/private-fixtures`; they are never public examples or bundled source. Compatibility evidence applies to this verified Windows environment; other Windows builds require their own golden comparison.
