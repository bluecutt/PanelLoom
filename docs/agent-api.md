# Agent API v1

## 0.2 preview additions

`object.reorder(kind=panel|balloon,direction=up|down)` exchanges one actual same-kind neighbor. Boundary returns NoChange; locked targets refuse. Optional `objectOrder.panels/balloons` arrays contain every live ID exactly once, last is front; absent arrays keep numeric legacy sorting. `object.layer` remains the precise numeric route.

`balloon.panelOcclusion(panelId,position=front|back|inherit,autoOrder=false)` is independent of `balloon.clip`. Front can cover chosen inset artwork and its border without removing unrelated/shared-parent lines. Back paints actual transparency once. The optional boolean `autoOrder` was added in 0.2.0-preview.2: true moves only the selected balloon to the nearest legal slot when needed, preserving every other object's mutual order and records. GUI occlusion controls enable it by default. Missing/false retains strict API1 behavior: cycles reject atomically, with no implicit reorder. Locked targets still reject; genuinely contradictory panel relations cannot be solved by moving one balloon and remain atomic errors. No clipping, transforms or source assets change.

Apply and dry-run return `data.outcomes` with operationIndex, op, targetId, code and optional data. Snap reports Moved/AlreadyAligned/NoCandidate/Unsafe; data includes targetPanelId, targetEdgeIndex (zero-based), distance. No-op live requests report the actual unchanged revision/hash. Optional response fields preserve API1 clients.

Occlusion outcomes report `Placed`, `OrderAdjusted` or `NoChange`; data contains `panelId`, `position`, `autoOrder` and signed `layerDelta` (positive toward front, negative toward back, zero unchanged). Relation plus selected-balloon reorder is one transaction/Undo, and dry-run reports both. Read the latest capabilities before sending `autoOrder` to older releases. Asset initialization/replacement and live write authorization are unchanged.

`ComicEditor.Cli.exe` is the native console entrypoint. stdout is one UTF-8 JSON envelope, never image Base64. Project format is `ComicPanelEditorProject` version 2. `capabilities` returns the authoritative action registry, supported commands and flag syntax. `--help`, `help` or a command's `--help` returns JSON usage without requiring that command's input files. GUI open, local sessions and portable bundles are implemented.

Commands: `inspect --project`, `validate --project`, `init --manifest --out`, `apply --project --patch --out [--dry-run]`, `render --project --out [--scale 2.5] [--object ID] [--padding N]`. Numbers use invariant decimal points. Ordinary timeout is 30 seconds; `--timeout` can extend a render (maximum one day). `--memory-limit-mib` defaults to 1024; refusal never silently lowers resolution.

The manifest follows `schemas/init-v1.schema.json`; relative source paths resolve through its project's assetBase relative to the manifest directory. It supplies the complete approved framework and explicit source placement. No automatic composition guesses, clipping of source files, or raster re-encoding.

The patch follows `schemas/patch-v1.schema.json`: API1, UUID requestId, current source SHA256 baseProjectHash, and a maximum 1000 registered operations. Object identifiers are explicit and kind-specific. Unknown actions or args reject the whole batch. `asset.replace` preserves every other object; differing or unavailable previous dimensions require explicit `fitPolicy`. Missing, moved or unreadable previous assets can be re-linked to a valid new source with ASSET_RELINK warning. `preserve` retains transforms; `refit` restores panel offsets/scale or contains a balloon's new aspect inside its prior rectangle centered. Existing initial/reset fields are not replaced. `object.layer` accepts zIndex and/or panel-only integer readingOrder; it never accepts readingOrder for balloons.

Existing output is refused unless `--overwrite --if-output-hash SHA256` matches that exact file. Applying to the input file also requires the patch's matching source hash, rechecked immediately before commit. Retrying with the old source hash cannot apply the translation twice. Successful replacements retain a backup. Prefer a new output path. dry-run reports full proposed project and structural diffs without creating output/report files. `inspect` includes full raw JSON, asset paths/dimensions/hashes and resolution assessment.

Responses always contain apiVersion, requestId, success, code, message, data, changedObjects and warnings. changedObjects use `panel:ID`, `balloon:ID`, or `page`; data.changes contains JSON Pointer before/after values. Exit codes: 0 success; 2 args/structure; 3 source/I/O; 4 hash/revision conflict; 5 lock/permission; 6 cancellation/busy/timeout; 70 unexpected internal failure.

`--request-id` must be UUID and agree with a supplied patch requestId. `--report` writes a new JSON receipt after a successful non-dry-run command. Paths matching request input or output are rejected before mutation. If another process blocks the report after the output commits, stdout still returns the truthful successful receipt with REPORT_NOT_WRITTEN warning. No remote network listener or arbitrary script/evaluation endpoint exists.
