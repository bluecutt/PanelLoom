# 并存、迁移和回退

0.2 候选与0.1候选并存，不替换默认入口。可选 objectOrder/panelOcclusion 需要新版才能保证相同排序与遮挡；旧程序可能忽略这些字段，不能把旧程序回存视为无损。发布目录、用户工作工程和安装个人 skill 是独立步骤，本次只交付便携候选。

预览版不移动或修改旧工具、原工程、原图和已安装 skill。首次打开旧 v2 工程后先另存独立副本；原文件可以继续用旧程序。新的命令与初始化文件不自动覆盖未保存 GUI 状态。

需要回退时关闭新应用，打开仍保留的旧程序和原工程。若希望旧程序打开新副本，先检查未知字段和 SingleLine 支持；旧程序可能忽略新属性，使用另外的回退副本，不能直接覆盖新的工作文件。保存备份及恢复快照是恢复资料，不默认替换正式稿。

发行程序的 portable Data、工程 JSON、素材目录属于三种不同数据。迁移完整漫画工程时使用 bundle，将整个工程包搬走；迁移应用时搬整个发行文件夹。默认用户 Data 不在应用包里；有意迁移状态需用户单独选择，不能顺手公开。

配套 skills/comic-page-workflow 是可迁移的本地草案；尚未安装进个人 skill 目录。正式替代旧 skill 和公开 GitHub 需要后续单独批准。中性 contracts 配置由创作者自己的项目提供，本包不夹带私人角色设定。
