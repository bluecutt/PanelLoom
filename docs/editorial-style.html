文案约定

正文说明用途、操作和结果，采用简洁的开发者口吻。介绍先给出产物预览，再交代流程；详细许可、隐私和素材说明放独立页面，步骤中保留影响保存、覆盖和授权的必要提醒。

使用直接陈述，减少否定式对比、宣传句与重复边界说明。新增正文省去创作者的漫画名称、世界观和私人设定。真实提示词中的必要人物称呼可以保留，原文与编者说明分别标注。

说明图使用镜头与动作名称，不显示本机路径、原始来源章节、版本账本或工程字段。开发者 API 文档保留必要的字段和协议值。图片各自承担一种说明任务，文字介绍实际操作，不复述全部画面。

历史对话仅选取确实存在的消息；缺失回复说明缺失。新操作示例标为新版演示，不冒称历史原文。许可文本保持标准原文。
