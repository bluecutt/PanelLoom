# 原生候选验收

0.2 的交互/性能与新增关系验收另见 [升级验收](2026-10-01-usability-upgrade-acceptance.md)，各项仍需用户操作确认。

## 已有证据

- 真实旧 P03/P05/P09/P10 Legacy 及 P10 SingleLine 解码像素完全一致（差异为零）。高清输出从完整原图读取。
- 独立分镜多边形、尺寸和顶点不强制共享；单线去重和限框气泡边线保护有斜边/透明度/层级回归。
- 共用注册操作覆盖 GUI 和 CLI。人工拖动/Agent 整批修改可一次撤销；旧工程未知字段保留。
- 实际获焦点参数控件滚轮不改数值、文本撤销不误撤工程、顶点模式体内点击仅选择。
- 属性编辑只提交实际改动的字段；切换顶点/边编号会读取该点坐标/显隐。拖回起点不生成残留移动记录，同层命中与实际绘制顺序一致。
- 初始化/首次修改会保留缺失的初始锚点；缺失素材可以用明确取景策略重新关联，CLI 提供 JSON 帮助与相对路径规范化。
- P09/P10 实际 GUI＋CLI 流程及真实用户输入桌面窗口已验证。
- 自包含双 EXE 移到中文空格路径，禁用本次进程 dotnet 查找仍启动、连接只读会话并导出中性示例。
- 公共源/包隔离扫描、hash manifest、运行时冲突拒绝、版本和 .NET notices 有测试。

## 用户逐项验收（仍待确认）

- [ ] 打开自己的工程，面板/气泡/小格形状、独立大小和层级符合原习惯。
- [ ] 查看/图片/分镜框/顶点/气泡五种模式，鼠标、滚轮、键盘和撤销手感无误触。
- [ ] 图层裁切/跨格、单线粗细及实际画面局部没有不可解释差异。
- [ ] 侧栏分区、窗口大小、导入和保存/恢复操作顺手。
- [ ] 开启/关闭 Agent 写入，精确更换一幅图和一个带字气泡；不覆盖其他人工微调。
- [ ] 在没有 SDK/没有 .NET 的另一台兼容 Windows 上运行两个入口、移动工程并高清导出。
- [ ] 用另一个标准用户验证管道不可访问当前用户会话；本机同用户测试不能代替这一项。
- [x] 软件许可确定为 AGPL-3.0-only，案例使用条件独立记录。
- [ ] 完成发行素材与文档审核，独立批准公开发布。

未勾选项不伪报成功；新应用保持并存预览，旧工具/skill 保留。公开源码候选中的 `Test.ps1 -Suite Public` 不含私人漫画 golden；完整 All/UiAll 需要本地私有样例。运行成功仅代表相应套件，不等于全部用户验收。
